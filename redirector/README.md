# 🚀 Vercel Akıllı QR Yönlendirici (0 TL - Sabit QR Kod Çözümü)

Bu klasör, masalara basılan **SABİT QR Kodların** hiç değişmeden kalmasını ve 4G/5G kullanan müşterilerin 0.05 saniyede kasaya yönlendirilmesini sağlayan **%100 ÜCRETSİZ Vercel Serverless** projesidir.

---

## ⚡ 1 Tıkla Vercel'e Yayınlama (Deployment)

1. [vercel.com](https://vercel.com) adresinden **%100 Ücretsiz (Hobby Plan)** bir hesap açın.
2. Bu `redirector` klasörünü Vercel hesabınıza yükleyin (Vercel CLI veya GitHub reposu ile).
   - Vercel CLI ile yüklemek için Terminalde:
     ```bash
     cd redirector
     npx vercel --prod
     ```
3. Vercel size ömür boyu **SABİT** ve ücretsiz bir adres verecektir (Örn: `https://oses-kadikoy.vercel.app`).
